# Components

## Po-prefixed PascalCase component names
Name every Vue component file PascalCase prefixed with `Po` (e.g. `PoUsersIndex.vue`), placed in the `components/<feature>` folder matching the `Inertia::render()` namespace, not the default `Pages/` convention.
